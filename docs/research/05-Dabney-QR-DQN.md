# 文献研读 #5：分位数回归与精准风险对冲 (QR-DQN)

## 1. 文献基本信息
- **标题**: Distributional Reinforcement Learning with Quantile Regression
- **发表日期**: 2018 (AAAI)
- **核心理论**: QR-DQN (Quantile Regression DQN)

## 2. 核心价值解析
- **灵活性**: 摆脱了 C51 对收益范围 (Vmin, Vmax) 的硬编码依赖，自动适应农业产出的宽幅波动。
- **风险刻画能力**: 通过固定分位数（Quantiles），提供了直接度量极端气候下“最差回报”的数学工具。

## 3. 对本项目的启示
- **主动避险决策**: 我们的 Agent 目前是“乐观派”（最大化期望）。QR-DQN 允许我们通过控制分位数权重，训练出“稳健派”Agent，这在面临气候极端波动（如您的兴趣点 C）时至关重要。
- **损失函数优化**: QR-DQN 的 Huber Loss 能够有效过滤气象数据中的噪声，使训练过程更平滑。

## 4. 实验方案：DSSAT-QR-CVaR-Optimizer
- **核心逻辑**: 升级 Rainbow 至 QR-DQN，并在推理阶段引入 CVaR 准则进行动作选择。
- **目标**: 证明在极端气候情景下，基于分位数的稳健决策优于传统的期望最大化决策。
- **评分**: 9.3 (理论严谨，针对性极强，复现难度略高)
