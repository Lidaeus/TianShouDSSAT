# 文献研读 #9：专家预训练与动作掩码引导

## 1. 文献基本信息
- **标题**: Deep Reinforcement Learning for Crop Management with Action Masking and Expert Pre-training
- **核心理论**: 模仿学习 (IL) / 行为克隆 (BC) / 动作掩码 (Action Masking)
- **核心思想**: 利用现有的农业专家规则（Heuristic Rules）为强化学习提供“热启动”。

## 2. 核心价值解析
- **跨越“死亡之谷”**: 解决了 RL 早期因盲目搜索导致的长达数千步的无效训练期。
- **安全性保障**: 通过动作掩码禁止生物学上明显错误的决策，确保了训练过程的物理合理性。

## 3. 对本项目的启示
- **离线数据利用**: 我们其实可以先手动运行一些高产量种子（Seed），将其轨迹作为“英雄数据”供 Agent 学习。
- **降低收敛难度**: 对于番茄这种复杂的作物，专家引导可以帮助模型快速识别出“营养生长”与“生殖生长”转换的关键节点。

## 4. 实验方案：DSSAT-Expert-Warmup-BC
- **核心逻辑**: 第一步：运行启发式规则生成离线数据集；第二步：有监督预训练策略网络；第三步：加载权重进行强化学习。
- **目标**: 实现训练曲线的“平滑起步”，将最终收敛到的产量潜力提升一个量级。
- **评分**: 8.8 (极具工程实战价值，是解决“训练慢”问题的良药)
