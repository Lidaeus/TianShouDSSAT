# 文献研读 #2：分布强化学习与收益风险建模

## 1. 文献基本信息
- **标题**: A Distributional Perspective on Reinforcement Learning
- **核心理论**: 分布强化学习 (Distributional RL) / C51 算法
- **核心思想**: 学习累积回报的完整概率分布 Z，而非仅学习期望值 Q。

## 2. 核心价值解析
- **信息丰富度**: 揭示了回报的方差、偏度和多峰性，这在具有高度不确定性（如气候变率）的环境中至关重要。
- **稳定性**: 分布贝尔曼算子在理论上具有更好的收敛性质。

## 3. 对本项目的启示
- **风险规避**: 农业决策本质上是风险管理。通过 Z 分布，我们可以实现“悲观估计”下的稳健灌溉策略。
- **异常气候识别**: 分布中的多峰性可以反映出不同气象情景（如多雨年 vs 旱年）对收益的不同预期，从而引导智能体识别当前处于何种气候模式。

## 4. 实验方案：DSSAT-DistRL-Risk-Aversion
- **核心逻辑**: 在 Rainbow 的基础上，将动作选择准则从“均值”改为“风险敏感度量（如 CVaR）”。
- **目标**: 提升模型在极端气候年份（旱年、热浪）的生存率和保底收益。
- **评分**: 8.5 (高相关性，中等实现难度)
