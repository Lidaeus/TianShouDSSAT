# 文献研读 #8：状态不确定性与 POMDP 稳健管理

## 1. 文献基本信息
- **标题**: Robust crop management under state uncertainty using POMDPs
- **核心理论**: POMDP (部分可观测马尔可夫决策过程)
- **核心思想**: 解决传感器噪声、观察缺失情况下的决策稳定性。

## 2. 核心价值解析
- **信念状态维护**: 强调了智能体必须基于“历史记忆”而非“瞬时快照”进行决策。
- **抗噪能力评价**: 提出了农业 RL 模型在非理想观测下的稳健性评价体系。

## 3. 对本项目的启示
- **优化 history_len**: 我们可以通过实验找到最经济的窗口长度。太短（如 1-3）不足以过滤噪声，太长（如 > 30）会引入过时的干扰并增加计算压力。
- **特征工程的抗噪化**: 在选择 `obs_keys` 时，应优先选择那些在物理意义上具有“惯性”的指标（如土壤深层含水量），因为它们受瞬时测量噪声的影响较小。

## 4. 实验方案：DSSAT-POMDP-Sensor-Noise-Robustness
- **核心逻辑**: 在特征提取层注入人工高斯噪声和随机观察缺失。对比不同 history 长度下的策略性能下降率。
- **目标**: 证明滑动窗口架构在应对非理想传感器数据时的优越性，提升系统的实战可靠性。
- **评分**: 9.1 (极具工程实战价值，支撑 v3.0 的稳健性指标)
