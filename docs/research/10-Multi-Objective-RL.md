# 文献研读 #10：多目标强化学习与可持续农业 (2022)

## 1. 文献基本信息
- **标题**: Multi-objective reinforcement learning for sustainable agriculture
- **发表日期**: 2022
- **核心理论**: 多目标强化学习 (MORL) / 帕累托最优 (Pareto Optimality)

## 2. 核心价值解析
- **打破“高产迷思”**: 证明了单纯追求产量最大化会导致不可持续的环境成本。
- **决策灵活性**: 允许通过调节权重向量 $\vec{w}$，在同一模型架构下实现不同地域属性（如缺水区 vs 环保区）的策略定制。

## 3. 对本项目的启示
- **奖励函数的广度**: 我们的系统目前还没有考虑“淋洗惩罚 (Leaching Penalty)”。引入该指标不仅能提升环保性，还能反向促使智能体学习更精准的“根系层施肥”逻辑。
- **生态评估维度**: 我们可以利用 MORL 的思想，为玉米和番茄分别设计一套“可持续性评分卡”，作为模型评价的最终指标。

## 4. 实验方案：DSSAT-MORL-Pareto-Efficiency
- **核心逻辑**: 将奖励函数重构为四维向量，并实现动态权重分配机制。
- **目标**: 寻找产量与环境足迹的最佳平衡点，实现“产量减损最小，环境获益最大”。
- **评分**: 8.8 (符合时代趋势，实操性强)
