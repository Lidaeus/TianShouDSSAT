# 文献研读 #11：基于遗传算法引导的“师生制”强化学习 (2026)

## 1. 核心构想 (User Concept)
- **核心逻辑**: GA (Teacher) -> DSSAT 30年历史数据优化 -> 生成 30组帕累托最优轨迹数据集 -> BC/Offline RL (Student) -> 继续训练 (Online RL)。
- **目标**: 在无实测案例的情况下，利用物理引擎的全局最优解为 AI 建立坚实的“生理与气象认知”基础。

## 2. 核心价值解析
- **高质量热启动**: 相比于随机初始化，从 GA 选出的最优方案起步，AI 的起点即是专家的终点。
- **气象模式压缩**: 30 年的气候波动被 GA 压缩成了 30 组“应对范式”，极大提升了模型对抗极端气象的“底气”。

## 3. 实验方案设计：DSSAT-GA-Teacher-Distillation
- **第一阶段 (GA 数据采集)**: 
    - 使用 Python 的 `pymoo` 或 `DEAP` 库作为优化器。
    - 针对 1980-2010 年，每年运行一次 GA，优化目标为 [Yield, -Cost, -Leaching]。
    - 记录下每年帕累托前沿上的管理轨迹。
- **第二阶段 (知识蒸馏)**: 
    - 将上述轨迹转化为 `tianshou.data.Batch` 格式。
    - 进行行为克隆 (BC) 预训练，使 Rainbow DQN 的网络初步具备判断“什么状态对应什么水肥”的能力。
- **第三阶段 (进化训练)**: 
    - 在随机年份环境下进行继续训练，让 AI 超越 GA 的静态策略，学会动态闭环控制。

## 4. 评估与评分
- **评分**: 9.4 (极具前瞻性，是目前最稳健的研究路径)。
