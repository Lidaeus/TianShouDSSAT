### Task 4: 安装 gym-dssat-pdi 并执行冒烟测试

**Files:**
- Create: `tests/smoke_test_env.py`

**Step 1: 编写冒烟测试脚本**

编写一个简单的脚本，尝试初始化 `gym-dssat` 环境。

```python
import gymnasium as gym
import gym_dssat_pdi

def test_env_init():
    try:
        env = gym.make('gym_dssat_pdi:GymDssatPdi-v0')
        obs, info = env.reset()
        print("Environment initialized successfully!")
        print(f"Observation keys: {obs.keys()}")
        env.close()
    except Exception as e:
        print(f"Failed to initialize environment: {e}")
        exit(1)

if __name__ == "__main__":
    test_env_init()
```

**Step 2: 执行冒烟测试**

Run: `conda activate wheat-rl && python tests/smoke_test_env.py`
Expected: "Environment initialized successfully!"

