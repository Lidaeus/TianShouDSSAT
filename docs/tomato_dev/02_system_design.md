# 第二章：解耦式系统架构设计

## 2.1 分离原则：普遍性 vs 特异性
我们引入了元配置架构。将底层通讯机制（普遍性）与特定作物的参数映射（特异性）彻底解耦。

## 2.2 多作物包装器 (DssatGenericWrapper)
`DssatGenericWrapper` 扮演了“环境路由器”的角色，通过配置矩阵维护每种作物的观察键名、模板和资源映射，并解决了物理引擎对文件路径长度的限制。

## 2.3 动态 PDI 模板注入机制
这是本项目的核心突破。通过修改 `DssatPdi.__init__` 增加 `pdi_template_path` 参数，允许外部根据作物类型动态注入 PDI 同步点定义，彻底消除了死锁风险。
