# 第一章：需求背景与科学挑战

## 1.1 精准农业背景下的多作物决策优化
全球粮食安全与水资源匮乏要求农业管理必须向精准化转型。强化学习（RL）因其处理复杂动态系统的能力，成为精准灌溉与施肥的最佳工具。然而，现有的农业仿真环境大多针对单一作物设计，难以支持多作物并行对比研究。

## 1.2 现有框架的局限性
官方 `gym-dssat-pdi` 框架深度耦合了 CERES-Maize 模型。其局限性体现在：硬编码依赖（变量名耦合）、环境隔离（缺乏动态资源支持）以及协议陈旧（不兼容 Gymnasium 1.x）。

## 1.3 番茄 (Tomato) 的特异性需求
番茄模型（基于 CROPGRO）与玉米模型存在本质生理差异，涉及不同的物候期定义（vstage）、种植模式（移栽）以及产量映射标识符（SDWT）。核心挑战在于如何在不破坏原有稳定性的前提下，实现一套通用的适配方案。
