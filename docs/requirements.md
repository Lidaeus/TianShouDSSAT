# 小麦强化学习优化系统需求文档 (Requirements Document)

## 1. 引言
本项目旨在利用强化学习（RL）技术优化小麦种植过程中的灌溉和施肥决策。通过集成 DSSAT 作物生长模型与天授（Tianshou）强化学习框架，构建一个能够模拟小麦生长环境并学习最优管理策略的智能系统。

## 2. 目标
*   实现小麦生长环境的精确模拟（基于 DSSAT Nwheat 模型）。
*   开发能够处理离散或连续动作空间（水、肥管理）的 RL 智能体。
*   通过多维度奖励函数平衡产量提升与资源投入（水、肥）。
*   验证最新强化学习理论在农业决策中的有效性。

## 3. 功能需求

### 3.1 环境模拟 (Environment Simulation)
*   **模型支持**: 支持 `gym-dssat-pdi` 内置集成的 DSSAT 内核版本（通常基于 v4.7.5 稳定分支）。
*   **接口协议**: 遵循 Gymnasium 协议。对于旧版 Gym 接口需通过 `shimmy` 提供兼容性支持。
*   **输入配置**: 系统需能够加载特定的气象 (.WTH)、土壤 (.SOL)、品种 (.CUL) 和实验方案 (.SNX) 文件。
*   **状态空间 (Observation Space)**: 包含但不限于：
    *   作物生长阶段 (`istage`)。
    *   叶面积指数 (LAI)。
    *   土壤水分含量。
    *   土壤氮素含量。
    *   历史气象数据（降雨、辐射、气温）。

### 3.2 动作空间 (Action Space)
*   **离散动作**: 预设梯度的氮肥施用量和灌溉量（如：不操作、50kg N/ha、20mm 灌溉等）。
*   **连续动作**: 精确输出氮肥量（kg/ha）和灌溉量（mm）。

### 3.3 奖励函数 (Reward Engineering)
*   **最终产量**: 季末产量奖励。
*   **资源成本**: 对灌溉水和氮肥的使用进行负反馈惩罚。
*   **生长潜力**: 在生长过程中加入 LAI 增量等中间奖励，解决稀疏奖励问题。
*   **风险控制**: 模拟小麦“死亡”情况，对于因管理不当导致的小麦过早死亡给予重大负惩罚。

### 3.4 训练与评估
*   **并行采样**: 支持多进程（SubprocVectorEnv）并行环境采样。
*   **多样性训练**: 支持加载不同年份的气象数据以提高泛化能力，防止过拟合。
*   **离线预训练**: 支持从已有实验数据（Offline RL）中进行初步学习。

## 4. 非功能需求
*   **性能**: 在 16 核以上的 Linux 服务器上实现高效并行训练。
*   **稳定性**: DSSAT 引擎运行稳定，能够处理异常输入。
*   **可扩展性**: 方便后续更换 RL 算法或调整作物模型参数。
*   **易用性**: 在易用性和专业性之间取得合适的平衡

## 5. 运行环境要求
*   **OS**: Ubuntu 22.04/24.04 LTS。
*   **Python**: 3.10 - 3.12。
*   **关键库**: Tianshou v1.0.0+, PyTorch v2.4+, Gymnasium, gym-dssat-pdi.
