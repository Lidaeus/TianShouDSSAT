# 小麦强化学习优化系统技术路线与规划 (Roadmap)

## 阶段一：环境准备与 DDD 基础 (已启动)
*   **1.1 基础软件安装**: 配置 Linux 环境，安装 Conda, gfortran, cmake、天授。
*   **1.2 DSSAT 编译**: 编译并验证 `gym-dssat-pdi` 及其集成的内核。
*   **1.3 DDD 规范确立**: 确立文档驱动开发流。
*   **1.4 冒烟测试**: 验证 Gymnasium 与 DSSAT 的基础链路。

## 阶段二：增强型环境与状态工程 (当前重点)
*   **2.1 WheatEnv 开发**: 实现动作映射、时序 Buffer 和预报特征注入。
*   **2.2 防御机制实现**: 编写异常捕获逻辑与动作掩码（Action Masking）。
*   **2.3 复合奖励函数**: 实现包含 LAI 引导和物候期评分的奖励逻辑。

## 阶段三：先验知识集成与模仿学习
*   **3.1 专家策略模拟**: 编写脚本运行标准农业规则，生成 `Expert Buffer`。
*   **3.2 行为克隆预训练**: 实现初步的策略模仿，避免冷启动。
*   **3.3 基准算法部署**: 在预训练基础上启动 Rainbow DQN 训练。

## 阶段四：并行训练与多目标优化
*   **4.1 并行化调优**: 使用 `SubprocVectorEnv` 进行大规模并行采样。
*   **4.2 超参数搜索**: 调整过程奖励与季末奖励的权重分配。
*   **4.3 泛化性验证**: 在多种历史气象年份（ dry/wet/normal years）下交叉验证。

## 阶段五：结果分析与系统交付
*   **5.1 对比分析**: 产出 RL 策略与专家策略的对比报告。
*   **5.2 模型导出**: 导出高性能策略 Checkpoints。
*   **5.3 最终文档同步**: 完善设计文档、部署手册及项目总结。
